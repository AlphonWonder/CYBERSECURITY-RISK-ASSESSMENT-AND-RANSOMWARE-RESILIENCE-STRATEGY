# Cybersecurity Risk Assessment and Ransomware Resilience Strategy for a Multi-Site Healthcare Provider

## Project Overview

This project focuses on assessing cybersecurity risks and developing a ransomware resilience strategy for a simulated multi-site healthcare provider. Healthcare organisations depend on digital systems to manage patient records, appointments, billing, communications, and other critical services. A ransomware incident can disrupt these systems, compromise sensitive information, and affect continuity of care.

The project aims to identify potential security weaknesses, assess their associated risks, and recommend practical measures to strengthen cybersecurity, incident response, and recovery capabilities.

## Problem Statement

Healthcare providers face cybersecurity challenges such as excessive user privileges, inconsistent security updates, limited security monitoring, inadequate backup testing, and unclear incident response responsibilities. These weaknesses can increase the likelihood and impact of ransomware incidents.

This project examines these risks within a simulated healthcare environment and proposes a structured approach to reducing exposure and improving organisational resilience.

## Project Objectives

- Identify critical information assets and potential cybersecurity threats.
- Assess vulnerabilities and prioritise risks based on likelihood and impact.
- Evaluate relevant security controls in a controlled laboratory environment.
- Develop recommendations for ransomware prevention, detection, containment, and recovery.
- Examine backup integrity, restoration procedures, and business continuity requirements.
- Propose an incident response framework and a practical implementation roadmap.

## Scope

The simulated environment represents a healthcare provider operating two facilities with approximately 80 employees. Its assumed technology environment includes:

- Electronic patient record systems.
- Appointment scheduling and billing applications.
- Cloud-based email and collaboration services.
- Shared file storage and network infrastructure.
- Employee accounts and access privileges.
- Backup, recovery, and incident response processes.
- Third-party technology services.

These details are scenario assumptions for research and will be validated against the approved project baseline where applicable.

## Methodology

The project will follow a structured risk assessment and resilience planning process:

1. **Asset identification:** Identify critical systems, data, services, and dependencies.
2. **Threat and vulnerability assessment:** Examine potential ransomware attack paths and security weaknesses.
3. **Risk analysis:** Rate identified risks using likelihood and impact criteria.
4. **Security control assessment:** Review relevant safeguards and test selected controls in an isolated laboratory.
5. **Backup and recovery assessment:** Evaluate backup protection and restoration using synthetic data.
6. **Incident response planning:** Develop response procedures and conduct a tabletop exercise.
7. **Risk treatment and recommendations:** Prioritise improvements and propose an implementation roadmap.

The NIST Cybersecurity Framework 2.0 and relevant ransomware and incident response guidance will inform the assessment.

## Ethical and Safety Considerations

This project is designed for educational and defensive cybersecurity research. Testing will be restricted to authorised, isolated laboratory environments and synthetic data. No real patient information will be used. Any engagement with an actual organisation will require prior written authorisation and appropriate supervisory approval.

The project will not conduct unauthorised scanning, exploitation, ransomware deployment, or disruption of live healthcare systems.
